# Ticket keywords that raise a risk flag during triage.
#
# Format:  flag: keyword, keyword, stem*
#   keyword   matches the whole word or phrase (case-insensitive)
#   stem*     matches any word starting with the stem
#
# A raised flag is not a verdict. The orchestrator must either confirm it as a
# signal (--signals) or dismiss it with a reason (--dismiss "flag:reason").
# Flags left unaddressed are treated as confirmed, so a risky ticket cannot be
# downgraded silently. Flags must be names route.sh knows (see route.sh --help).
